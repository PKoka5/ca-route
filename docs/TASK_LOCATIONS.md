# Task travel destinations

Reviewed on 3 October 2026. Every one of the 655 bundled Combat Achievement tasks
has a destination. The 91 activities share 66 distinct public approach points.
`ActivityDestinationsTest` enforces full catalogue coverage; `GuideControllerTest`
selects every bundled task and checks its marker and Shortest Path target.

The point is an entrance, public landing or staging location. Dungeon entrances do
not automatically guide the final room inside; use Travel details for the manual
continuation. Quest bosses use replay approaches, not the original quest instance.
Shortest Path chooses paths and transports from its own settings and account
access. A target request does not establish that a route was found.

Into the Den of Giants (398) uses its exact Shayzien cave. Sit Back and Relax (399)
can be completed with suitable creatures anywhere: its Varrock Sewers point is an
explicit suggestion, not a location requirement. Both special cases check the full
task identity. Unknown future activities receive no guessed destination.

Coordinate facts come from pinned RuneLite 1.13.1 World Map definitions and pinned
Quest Helper location definitions. The additional research record, including
monster-placement references, is in [navigation additions](../data/navigation-additions.json).
Attributions are in [third-party notices](../THIRD_PARTY_NOTICES.md).
The per-task CSV produced by the tests is
`build/navigation/task-destination-coverage.csv` (655 data rows).
